# 禅境花园优化

为禅境花园进行了一些功能上的优化。


## 新增按键

进入禅境花园后，界面左上会出现三个按钮：**整理**（执行重排）、**总览**（打开花园总览）和  **种满**（用植物余额填满当前页空位）。

### 整理按钮
点击后会将当前页的植物按种类重排，让同种植物排放在一起。整理只会作用于当前所在页，只调整「植物 → 槽位」的绑定。

### 总览按钮

点开后可以看到花园页总览，允许添加新的花园页，并对额外页进行管理。

1. 新增的花园页会复制默认的白天主花园页（48 个位置、全部解锁），突破原版每类花园的上限限制。
   - 新增页在**当前的玩家存档**里以 `zengarden.extraPages` 保存，页面 ID 取枚举外的 4、5、6…（删除过的低位 ID 会优先复用），重启后自动重建。
   - 新增页的植株也会保存在新增页的词段（和原版格式一致）。
   - 如果模组停用，原版游戏会保留但忽略这个额外字段，直到重新加载模组。

2. 删除自定义页时，**该页的植物会全部搬到其它花园**，从第一页开始，填满后会自动顺次往后找下一个花园页的空位，一株都不会丢。
   - 剩余所有页都放不下时，系统会拒绝删除；删除前有两级确认，并明确告知植物去向。

3. 重命名可以对额外页进行重命名（方便辨认）。

4. 额外页可以调节先后顺序（不改变原有四页）。 

### 种满按钮

一键用当前植株余额填满当前页的花盆空位；剩余植株不够时，只会种到剩余植株为0。
- 选苗沿用原版的已获得植物、奖章/熟练度、最近种植次数和 `FixedWeight` 权重，并执行槽位可种植判定。


## 功能优化

1. **手套 / 推车可以搬运待浇水的植物** —— 原版里植物在进入下一阶段（花盆冒金光）之前会被直接置灰，手套拿不起来、推车也推不走；现在两种方式都能移动。


## 兼容性

- 最低要求：GP-Next 1.5.5，客户端 0.16.1。
- 由于新版本更新可能会影响花园参数，因此更新前请做好存档备份。

## 安装

把 `zen-garden-optimize-1.0.0.zip` 导入 GP-Next（按 F9 打开模组面板 → Import ZIP）。
脚本模组需要先在 **Experimental → JS Modding** 里开启并按提示重启游戏。
